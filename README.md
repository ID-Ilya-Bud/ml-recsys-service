# ML-сервис рекомендаций

**Кратко**
Сервис рекомендаций с полным CI/CD пайплайном:
код -> автоматическая сборка образа -> версионированная публикация -> деплой на сервер через ansible с healthcheck.

Пет-проект для отработки практик: CI/CD, Docker, Ansible, версионирование образов, идемпотентный деплой.

**Схема пайплайна**

[код в GitHub] -> [GitHub Actions](flake8, docker build/push, два тега: latest и sha) -> [Docker Hub] -> [Ansible: pull, compose up, healthcheck] -> [VM: app:8000] -> [внешняя db (Postgresql)]

**Как устроено**

Запускается плейбук через WSL и подключается к VM по ssh ключу. С помощью CI/CD сервер не собирает образ, а берёт уже заранее готовый из Docker Hub`а. На самом сервер только compose up и .env.

**Почему я так сделал**

Пересобирал проект из прошлой идеи, т.к не понравилась. До этого образ собирался прямо на VM и его создание занимало часы,  перенёс сборку образа в CI и на VM остались только pull и up. Сократил этим время сборки до ~ нескольких минут 

**Откат**

С помощью sha тега каждая сборка получает этот тег, с хэшем коммита, и откат становится одной стракой.
